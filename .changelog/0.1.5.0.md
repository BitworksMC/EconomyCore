# 0.1.5.0

## Major Changes
- Restored Paper 26.2 startup compatibility with Lamp 4.0.0-rc.17 and TNIL 0.2.0.0-SNAPSHOT-3.
- Made Redis-backed cross-server synchronization an explicit, restart-required opt-in.

## Minor Changes
- Added `Data.Sync.Enabled`, defaulting to `false`, and upgraded the data configuration to version 7.
- Kept Redis disabled when the shared security token is missing or unchanged from its default.
- Disabled configuration synchronization by default and documented the Redis opt-in process.
- Preserved per-currency sync settings when saving or changing currency types.
- Preserved note enchantments and item flags across configuration saves, including legacy paths.
- Enforced project-wide cyclomatic complexity checks during Maven verification and CI.
- Refactored large command, menu, transaction, storage, currency, and platform paths into focused helpers.
- Replaced the unavailable custom update server with the BitworksMC GitHub Releases feed.
- Added complete Paper permission declarations for admin, module, and money commands.

## Fixes
- Prevented default configurations from initializing Redis, scheduling outbound sync, or registering plugin messaging channels.
- Disabled synchronization for the current startup when Redis cannot be reached.
- Normalized receipt participant and modifier UUIDs before binding them to SQL statements.
- Fixed MyEco enchantment and item-flag selection state and pagination keys.
- Fixed command replies on Paper 26.2 and corrected command registration across supported platforms.
- Fixed money conversion defaults, money-request permission checks, balance-top pagination, and transaction-history page bounds.
- Fixed balance history menus replacing earlier transaction icons when a page contains multiple receipts.
