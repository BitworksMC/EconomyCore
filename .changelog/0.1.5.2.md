# 0.1.5.2

Released September 17, 2026.

## Fixes
- Fixed Paper registry conversions for damage types, jukebox songs, instruments, Bukkit keyed values, and Adventure/Paper typed keys.
- Fixed converter lookup selecting an unrelated output mapping; prefer exact and most-specific compatible conversions deterministically.
- Reject different-material vanilla currency candidates before serializing their components.
- Fixed recursive rebuilding of shulker/container contents, bundles, charged projectiles, and use remainders; preserve child amounts, container slots, and nested-item comparisons.
- Preserve native attribute IDs, registry tags, optional tool-rule values, equipment data, instruments, jukebox data, and swing durations when rebuilding unchanged components.
- Preserve and compare persistent item data and item flags; return independent item stacks with the requested amount instead of sharing cached stacks.
- Added Paper capability checks and adapters for missing component fields, unbreakable component API changes, optional equipment/tool methods, and instrument getter return-type changes.
- Stage Paper/Folia inventory additions and removals before committing them, correct nested removal counts, and prevent partial withdrawals from reinserting container currency items.
- Update inventory and ender-chest wallet snapshots only after the corresponding item calculation succeeds.
