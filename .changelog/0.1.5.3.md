# 0.1.5.3

## Fixes

- Fixed custom currency losing its identity and becoming unusable when a full inventory sends it to an ender chest or drops it on the ground.
- Fixed items losing custom data or properties during transfers, including items inside shulker boxes and bundles.
- Fixed balance checks throwing `PLACED_ON` errors when players close inventories or log out.
- Fixed currency recognition when the server removes item flags that do not apply to the item.
- Fixed damage-type and armor trim material properties changing on Leaf 1.21.11.

Previously damaged items with missing custom currency tags still need to be replaced.
