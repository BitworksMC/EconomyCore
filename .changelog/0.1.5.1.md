# 0.1.5.1

## Minor Changes
- Updated Bukkit, Paper, and Folia metrics to the vendored bStats client with service ID 34093.

## Fixes
- Delayed Paper item compatibility initialization until enable so installed custom-item plugins can register their providers.
- Fixed startup on Paper 1.21.10 by disabling attack-range and minimum-attack-charge item conversion when the server API does not provide them.
- Fixed Paper inventory balance checks failing to serialize damage types and restored damage-type deserialization.
- Fixed balance-top placeholders displaying the next account's balance and failing on the last entry of a page.
- Fixed numeric balance-top placeholders returning no value when currency formatting includes symbols or separators.
